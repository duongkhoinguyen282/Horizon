## [LG monitors silently install software via Windows Update without user consent](https://videocardz.com/newz/lg-monitors-silently-install-software-through-windows-update-without-user-consent) ⭐️ 8.0/10

LG monitors are triggering the silent, automatic installation of third-party software through Windows Update as soon as they are connected to a PC. This process occurs without explicit user interaction or consent, leading to concerns regarding background system modifications. This practice raises significant security and privacy concerns, as it allows vendors to push software onto systems without transparency or sandboxing. It highlights a critical flaw in how Windows handles device metadata and third-party software distribution. The software is installed automatically upon device connection and gains full system access, persisting across reboots. Users can disable this behavior by modifying 'Device Installation Settings' in the Windows Control Panel or via Group Policy.

**Background**: Windows Update uses device metadata to automatically identify hardware and suggest relevant drivers or companion software. This incident mirrors historical security issues where automatic execution features were abused to install software without user oversight.

The release of Kimi K3 marks a significant milestone in AI development, demonstrating that non-Western labs are rapidly closing the capability gap with established frontier AI companies through advanced model distillation techniques. This development signals the commoditization of frontier-level AI, suggesting that the competitive landscape is shifting away from a monopoly held by a few Western labs toward a more globalized and accessible market. Kimi K3 is reported to have 2.8 trillion parameters, placing it in direct competition with top-tier models like ChatGPT 5.6 and Opus 4.8 while offering competitive pricing for input and output tokens.

hackernews · sbochins · Jul 18, 17:32 · [Discussion](https://news.ycombinator.com/item?id=48960218)

**Background**: Model distillation is a machine learning technique where knowledge is transferred from a large, complex model to a smaller, more efficient one. This process allows developers to create high-performing models that are cheaper to run and easier to deploy. Historically, this has been a key strategy for democratizing access to powerful AI capabilities.
